# Art direction and asset planning workflow

Which visual rule or asset gap most affects the intended experience in this pass?

## When to repeat

At each asset batch or milestone, and when camera, palette or visual scope changes.
Run one focused pass for the current request; return when new evidence or changed
assumptions make another pass useful. Do not load every reference or rerun every
check on every minor edit.

## Bring forward

The visual brief, representative gameplay view, approved assets and available asset budget.
If a previous record exists, review its decisions and unresolved findings before
planning. If it does not, establish a small baseline from the current game and
mark missing evidence explicitly.

## Run the cycle

1. Review the approved palette, shape language, material or pixel rules, silhouette hierarchy and camera scale. Compare the current gameplay view with the prior accepted representative set.

2. Choose a small asset batch that tests the largest visual uncertainty. State its role, scale, contrast and budget before generating or sourcing assets. Prefer reuse or procedural work when it meets the brief.

3. Inspect and integrate the actual returned files and registries. Check framing, dimensions, anchors, animation fit and provenance. Evaluate assets beside the existing game instead of accepting them from a standalone preview.

4. Play the representative scene to check focus and readability. Reconcile style exceptions explicitly, then update the asset plan before commissioning the next batch. Preserve a coherent direction across passes.

## Verify and decide

Check gameplay silhouettes and contrast at real camera scale, light/dark contexts where relevant, loading cost and whether every produced asset is actually used. Attractive source art does not prove useful game art.

A camera zoom makes detailed enemies unreadable. Revisit silhouette and value contrast with one representative enemy before replacing the whole asset library.

## Leave a record for the next pass

A visual-system decision sheet, asset provenance and an updated asset plan.

Keep the small approved representative set, visual rules, exceptions, source/license notes and remaining asset gaps. Preserve provenance and budget decisions as the game’s content grows.

Use an existing project note or the handoff when no durable note tool is offered.
Keep facts separate from assumptions. The next pass should be able to recover
what was tried, why it was chosen and what the evidence established.
