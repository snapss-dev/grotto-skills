# The Core of Gaming

Design or improve a game loop, challenge, progression, feedback, or playtest plan.

Build around the creator's player fantasy, a clear challenge, meaningful choices and readable consequences. Finish the requested playable loop, including failure and recovery; use playtest evidence to judge it.

Read only the reference needed for the current decision:

| When | Read |
| --- | --- |
| Choosing the player fantasy, verbs or meaningful decisions | [loop](references/loop.md) |
| Tuning feedback, learning, failure or progression | [feedback](references/feedback.md) |
| Exploring an idea in conversation | [brainstorm](references/brainstorm.md) |
| Scoping, brainstorming or reviewing a Studio game | [studio](references/studio.md) |
